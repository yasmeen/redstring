      Behind Corkboard Studio's pipeline

      The pipeline for creative agencies that pitch with real work. Red String screens every lead against your clients' audiences, traces every decision to its sources, and Double Take catches drafts that would look like another client's work to the same people, before they ship.

      This view shows what Red String does behind Corkboard Studio's dashboard: the FalkorDB graphs, the queries agents call, and the numbers behind every verdict.

      Graph architecture

      Each prospect or client gets its own private FalkorDB graph, client:<slug>. A shared agency graph holds only what the agency needs to compare clients: businesses, audiences, techniques, references, and fingerprints; when Producer writes a Draft in a client graph, P1 projects a Fingerprint into agency that holds technique IDs only, with no copy and no assets. Cross-client checks run only on agency, while threads and stale-draft checks run inside the client's own graph.
